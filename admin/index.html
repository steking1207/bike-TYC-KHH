    新增一次活動

    1. 最快的方式：在 Strava 活動頁按 ⋯ →「匯出 GPX」，回到後台按「從 GPX 匯入」選這個檔案（或直接拖進來）。會自動抓出日期、出發與抵達時間、每次停留的時間與里程，並猜是哪個休息點，確認後再微調即可。
    2. 或按「＋ 新增一次活動」手動填。會自動帶入下一個場次編號、今天日期、上一次的參加者和停靠點（時間與里程留空）。
    3. 依 Strava 紀錄逐站填到達、出發時間與累計里程。起點只填出發，終點只填到達。
    4. 這次沒停的站按 ✕ 刪掉；多停的站按「＋ 插入」，或先到「地點與網站」新增地點。
    5. 停留時間、區段距離、均速、總時間、休息時間都會自動計算，不用自己算。
    6. 爆胎、摔車、會合、中離等狀況加在「突發狀況」，填發生時的里程。在休息點發生的，就填那一站的里程。
    7. 右上角「預覽」先看效果，沒問題再按「發佈到 GitHub」，GitHub Pages 約 1 分鐘後更新。

    地點

    地點清單的順序就是路線順序（北到南），比較表的列依此排列。新地點請插在正確的位置。已被活動使用的地點不能刪除，店家關了請勾「已歇業」。

    權杖

    1. 開啟 GitHub → Fine-grained personal access token。
    2. Repository access 選 Only select repositories，選 bike-TYC-KHH。
    3. Repository permissions → Contents 設成 Read and write。

    權杖只存在你的瀏覽器（沒勾「記住這台電腦」時關掉瀏覽器就清除），只會送到 api.github.com。
